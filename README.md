# 은성 ♥ 소미 모바일 청첩장 — GitHub Pages 배포 안내

## 1. 파일 구성

```
wedding/
├── index.html        청첩장 페이지 (화면·동작 전부 이 파일 하나)
├── images/           웨딩 사진 19장(01.jpg~19.jpg) + 첫 화면 아치용(hero.jpg)
├── share/
│   └── kakao.jpg     공유 카드 이미지, 세로 (900×1200) — 카카오톡 공유 버튼과 링크 미리보기 모두 이 그림
├── music/
│   └── bgm.mp3       배경음악 (이 청첩장용으로 새로 만든 오르골 곡, 90초 반복)
└── README.md         이 문서
```

## 2. 미리 정해 둔 주소

| 항목 | 값 |
|---|---|
| GitHub 조직 | `develop-korea-tech` |
| 저장소 이름 | `wedding` |
| 청첩장 주소 | `https://develop-korea-tech.github.io/wedding/` |

조직이나 저장소 이름이 다르면 `index.html`에서 아래 **3곳**을 같은 주소로 바꿉니다. 주소 끝의 `/`는 꼭 남겨 둡니다.

1. `<meta property="og:url" content="...">`
2. `<meta property="og:image" content=".../share/kakao.jpg">`
3. 스크립트 맨 위 `CONFIG.siteUrl`

## 3. GitHub Pages에 올리기

1. https://github.com 에 로그인한 뒤 `develop-korea-tech` 조직의 **Repositories** 탭으로 갑니다.
2. 오른쪽 위 초록색 **New repository**를 누릅니다. **Owner**가 `develop-korea-tech`인지 확인합니다.
3. **Repository name**에 `wedding`을 입력하고 **Public**을 선택한 뒤 **Create repository**를 누릅니다.
   - 무료 계정은 공개(Public) 저장소만 GitHub Pages를 쓸 수 있습니다.
4. 새 저장소 화면의 **uploading an existing file** 링크를 누릅니다.
5. 압축을 푼 `wedding` 폴더 **안의** `index.html`, `images` 폴더, `share` 폴더를 브라우저 창으로 끌어다 놓습니다.
   - 폴더째 끌어다 놓으면 폴더 구조가 그대로 올라갑니다. `images/01.jpg`처럼 보이면 정상입니다.
6. 아래 **Commit changes**를 누릅니다.
7. 저장소 상단 **Settings** → 왼쪽 **Pages**로 갑니다.
   - 왼쪽에 **Pages** 메뉴가 없거나 켤 수 없으면, 조직 화면의 **Settings → Member privileges → Pages creation**에서 **Public**이 허용돼 있는지 확인합니다.
8. **Build and deployment**에서 Source는 **Deploy from a branch**, Branch는 **main**, 폴더는 **/(root)**를 고르고 **Save**를 누릅니다.
9. 1~2분 기다린 뒤 `https://develop-korea-tech.github.io/wedding/`를 열어 청첩장이 보이면 완료입니다.
   - 이 단계까지는 카카오톡 공유 버튼과 지도가 보이지 않는 것이 정상입니다. 4장에서 카카오 키를 넣으면 나타납니다.

## 4. 카카오 키 받기 (카카오톡 공유 버튼 + 지도)

카카오 개발자 사이트는 메뉴 이름이 자주 바뀝니다. 아래 이름이 다르면 같은 뜻의 메뉴를 찾으면 됩니다.

1. https://developers.kakao.com 에 카카오 계정으로 로그인합니다.
2. **내 애플리케이션** → **애플리케이션 추가하기**를 누릅니다.
   - 앱 이름: 예) `은성 소미 청첩장` / 회사명: 본인 이름
   - **테스트 앱이 아닌 일반 앱**으로 만듭니다. 테스트 앱은 지도 호출이 하루 100건으로 제한됩니다.
3. 앱 화면의 **앱 키** 중 **JavaScript 키**를 복사해 둡니다.
4. **JavaScript SDK 도메인**에 `https://develop-korea-tech.github.io` 를 등록합니다. 뒤에 `/wedding`은 붙이지 않습니다.
5. **플랫폼 → Web → 사이트 도메인**에도 같은 주소를 등록합니다.
   - 카카오톡 공유 메시지의 "청첩장 보기 / 위치 보기" 버튼은 여기 등록된 주소로만 열립니다.
6. **제품 설정 → 카카오맵 → 사용 설정**을 **ON**으로 바꿉니다.
   - 이걸 켜지 않으면 지도가 빈 화면으로 나옵니다.
7. GitHub 저장소에서 `index.html`을 열고 오른쪽 위 연필 아이콘(Edit)을 누릅니다.
8. 스크립트 맨 위 `kakaoKey: ""`의 따옴표 안에 3번에서 복사한 키를 붙여 넣습니다.
   ```js
   kakaoKey: "여기에_JavaScript_키"
   ```
9. **Commit changes**를 누르고 1~2분 뒤 다시 열어 봅니다.

JavaScript 키는 원래 웹페이지에 공개되는 용도의 키라 공개 저장소에 넣어도 됩니다. 4~5번에서 등록한 주소에서만 작동하도록 카카오가 막아 줍니다.

## 5. 확인 순서

1. 휴대폰으로 청첩장 주소를 엽니다.
2. "오시는 길"에 지도가 보이는지 확인합니다. 처음엔 고정되어 있고, 지도를 한 번 누르면 움직일 수 있습니다.
3. 맨 아래 **카카오톡 공유**를 눌러 "나와의 채팅"으로 보내 봅니다.
   - 세로 사진 카드와 "청첩장 보기 / 위치 보기" 버튼 두 개가 보이면 정상입니다.
4. 링크만 복사해 카톡에 붙여 넣어도 같은 세로 그림(`share/kakao.jpg`)으로 미리보기가 뜹니다.
   - 카톡은 한 번 읽은 미리보기를 한동안 저장해 둡니다. 내용을 고친 뒤 예전 미리보기가 뜨면 카카오 개발자 사이트의 **도구 → 공유 디버거**에 주소를 넣고 캐시를 초기화합니다.

## 6. 내용 고치기

| 바꿀 것 | 방법 |
|---|---|
| 사진 | `images/`에 **같은 파일 이름**으로 덮어 올리기 |
| 배경음악 | `music/bgm.mp3`를 같은 이름의 다른 mp3로 덮어 올리기. **사용 권한이 있는 음원만** (유명 가요·OST 음원은 저작권 문제) |
| 갤러리 순서·칸 크기 | `index.html`에서 `const G = [` 부분. `[사진 번호, 칸 크기, 얼굴 위치]` 순서 |
| 문구·계좌번호 | `index.html`에서 해당 글자를 검색해 수정 |
| 공유 카드 제목·설명 | `<head>`의 `og:title`, `og:description`과 스크립트의 `shareKakao()` 안 `title`, `description` |

## 7. 작동 원리

- **정적 페이지**: GitHub Pages는 올린 파일을 그대로 보내 주기만 합니다. 서버 프로그램이 없어서 관리할 것이 없고 무료입니다.
- **링크 미리보기**: 카톡·문자 앱은 링크를 받으면 페이지 `<head>`의 `og:` 태그(제목, 설명, `kakao.jpg`)를 읽어 카드를 만듭니다. 앱마다 세로 그림을 자르는 방식이 다를 수 있습니다.
- **카카오톡 공유 버튼**: 카카오 공유 모듈(SDK)이 "피드" 형식 메시지를 만듭니다. 세로 이미지 `kakao.jpg` 아래 제목과 날짜가 나오고, 버튼 2개가 붙습니다. 카카오는 키와 등록된 주소가 맞는지 확인한 뒤에만 보냅니다.
- **지도**: 카카오맵 모듈이 예식장 좌표에 지도와 표시를 그립니다. 페이지를 내리다가 지도가 끌려가지 않도록 처음엔 고정해 두었습니다.
- **키가 없을 때**: `kakaoKey`가 비어 있거나 카카오 모듈을 못 불러오면 카카오톡 공유 버튼과 지도만 숨겨지고, 나머지는 그대로 동작합니다. 이 경우 "링크 복사"는 항상 됩니다.
- **나무·꽃잎**: 화면의 동백나무는 그림 파일이 아니라 페이지가 직접 그립니다. 꽃잎은 방문자가 누르거나 꽃 위를 쓸 때만 떨어집니다.
  - 꽃이 다 피고 아무도 건드리지 않으면 나무를 한 장의 그림으로 저장해 두고 그것만 다시 붙입니다. 휴대폰 부담을 줄이기 위해서이고, 나무가 흔들릴 때만 전체를 다시 그립니다.
- **배경음악**: 자동으로 재생하지 않습니다. 오른쪽 위 "음악 켜기"를 눌러야 재생되고, 누르기 전에는 음악 파일도 받지 않습니다. 다른 앱이나 탭으로 가면 멈췄다가 돌아오면 이어서 재생합니다.
- **공개 범위**: 공개 저장소라 계좌번호를 포함한 파일 내용은 저장소 주소를 아는 누구나 볼 수 있습니다. 청첩장이 원래 링크로 퍼지는 것이라 같은 수준이지만, 검색엔진에는 노출되지 않도록 `noindex`를 넣어 두었습니다.
